# UI Lint and Format Action
## Description
Programmatically validates type-safety, tokenized layout structures, and accessibility standards within presentational layers.
## Triggers
- Custom slash command: `/ui-lint`
## Instructions
1. Inspect the local package manifests to identify the specific toolchains defined in this workspace.
2. Execute the local project linting or formatting engine natively.
3. Guarantee that all presentational updates pass automated interface checks and structural constraints before clearing the task.
